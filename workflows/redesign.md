# Workflow: UI Redesign

1. Inspect the existing site, routes, assets, components, content and user journeys.
2. Record what must remain unchanged: brand, copy, URLs, behavior, integrations and data flow.
3. Identify the UX problems with evidence rather than replacing everything by taste.
4. Produce a design direction and token plan before substantial code changes.
5. Prototype one representative page or section if scope is large.
6. Implement reusable patterns and responsive states.
7. Preserve existing functionality and accessibility.
8. Compare screenshots at representative viewport widths.
9. Run relevant interaction/browser tests and report any intentionally changed behavior.

Visual polish must not silently remove features or damage conversion flows.
