# Changelog

All notable changes to this project are documented here.

## [0.2.0] - 2026-11-11

### Added
- React + Vite + Supabase + Vercel integration profile.
- Supabase RLS test matrix.
- Independent Planner / Generator / Evaluator protocol.
- Feature contract and progress templates.
- Evaluator-loop workflow.
- Upstream source integration and provenance policy.

### Changed
- Master skill version and routing updated to 0.2.0.
- README now documents integrations, evaluator workflow, and validation boundaries.

### Notes
- This is a documentation and workflow foundation. No target WebApp was built or deployed by this release.
- Compatibility with each external coding-agent runtime and live stack versions still requires validation in real projects.

## [0.1.0] - 2026-11-11

### Added
- Initial portable Master WebApp Skill and module-routing contract.
- Core discovery, planning, architecture, and execution guidance.
- Design, frontend, backend, security, testing, performance, and deployment modules.
- New-project, existing-project, feature, redesign, and bug-fix workflows.
