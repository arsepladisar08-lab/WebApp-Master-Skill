# Performance and SEO

## Performance

- Establish a baseline before claiming improvement.
- Measure field data when available and lab data for controlled diagnosis.
- Review LCP, INP and CLS alongside bundle size, image weight, font loading and network waterfalls.
- Optimize the largest content element and avoid unnecessary render-blocking resources.
- Reserve image/media dimensions to prevent layout shifts.
- Reduce unnecessary client JavaScript and defer non-critical work.
- Test on representative devices and constrained networks where practical.

## SEO

For indexable public pages:
- Provide unique titles and useful descriptions.
- Use semantic heading structure and crawlable links.
- Set canonical URLs where needed.
- Configure robots and sitemap intentionally.
- Add structured data only when it accurately describes visible content and meets the relevant schema.
- Provide social sharing metadata and meaningful image previews.
- Avoid indexing private or authenticated application routes.

Do not promise a Lighthouse score without running the audit. Lab scores vary by environment; report conditions and metric results.
