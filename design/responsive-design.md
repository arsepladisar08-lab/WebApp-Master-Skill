# Responsive Design

- Start with the narrowest practical layout and progressively enhance.
- Choose breakpoints when content or layout needs them, not solely from device labels.
- Test at representative narrow mobile, large mobile, tablet, laptop, and wide desktop widths.
- Prevent horizontal overflow, clipped controls, unreadable line lengths, and touch targets that are too small.
- Reflow complex tables, navigation, sidebars, forms, and dashboards intentionally.
- Check zoom and text resizing; do not disable browser zoom.
- Verify keyboard navigation and focus visibility at every layout.
- Prefer flexible sizing, min/max constraints, grid and flexbox over fixed-width assumptions.
